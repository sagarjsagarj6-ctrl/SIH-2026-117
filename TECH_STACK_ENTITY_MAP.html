Entity Map — File Structure

Authentication & Security

server/middleware/
  • auth.js — JWT verify, user extraction, route protection
  • security.js — CORS, rate limiting, request ID tracking
  • rbacMiddleware.js — Role gates: Admin, Manager, Employee

API Routes

server/routes/
  • authRoutes.js — login, register, me, profile
  • agentRoutes.js — query, orchestrate, registry, decompose
  • documentRoutes.js — upload, list, delete, ingest
  • knowledgeRoutes.js — hybrid search, stats, rebuild index
  • inferenceRoutes.js — backends, generate, telemetry
  • workflowRoutes.js — queue, events, state transitions
  • auditRoutes.js — logs, export, PII scan

Agent Core

server/agents/
  • BaseAgent.js — Abstract agent with plan → execute → validate → report
  • AgentOrchestrator.js — Routes tasks to agents, manages execution modes
  • AgentRegistry.js — Agent registration, lookup, capability mapping
  • TaskDecomposer.js — Keyword heuristics for breaking down complex queries
  • AgentMemory.js — Per-agent session context storage
  • AgentAuditLogger.js — Full execution audit trail
  • ExplainabilityEngine.js — Trace agent reasoning & decisions

Specialist Agents

server/agents/specialists/
  • RAG Agent — Knowledge base retrieval, hybrid vector + BM25
  • DataScienceAgent.js — Statistical analysis, trend detection
  • VisionAgent.js — Image analysis, OCR with Tesseract fallback
  • ReportingAgent.js — Template-based report synthesis
  • ComparisonPredictionAgent.js — Comparative analysis & forecasting
  • HardwareManualAgent.js — Hardware documentation lookup

Config & Data Layer

server/config/
  • db.js — MongoDB connection via Mongoose 8
  • vectordb.js — Custom JSON ANN + BM25 index
  • datasources.js — External data source configuration
  • identity.js — JWT signing, token generation
  • agentTools.js — Tool permission service for agents

Services & Protocol

server/services/ & protocol/
  • notificationService.js — In-memory notification delivery
  • AgentMessage.js — Inter-agent message schema
  • AgentChannel.js — Agent communication channel abstraction
  • workflowRoutes.js — LAN workspace & workflow queue
  • qualityRoutes.js — PII detection & redaction
Agent Execution Flow

Multi-Agent Orchestration Pipeline

From user query → task decomposition → parallel/sequential agent execution → report

User Query
Natural language request from React frontend
Task Decomposer
Keyword heuristics split query into sub-tasks
AgentRegistry
Route sub-tasks to registered specialist agents
Execute Agents
Parallel or sequential execution per orchestration mode
Reporting Agent
Synthesize results into structured report
Explainability
Trace reasoning + audit log + PII redaction
